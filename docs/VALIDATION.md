# 第一版驗證紀錄

日期：2026-10-11。

環境：Linux、FFmpeg 7.1.5、Python 3.13.5、NumPy 2.2.4、SciPy 1.15.3、PyQt5 / Qt 5.15.15 離線介面相容路徑。
Windows 成品使用 Python 3.12、PySide6 / Qt6。此環境無網路安裝能力，因此未在此安裝 PySide6。

已驗證：

- 14 項核心測試：專案格式／非法設定、非破壞性剪輯、已知正負位移、低音量伴奏／濾波／反射／獨奏干擾、非相關／靜音音訊、音量比例與位移、超出影片範圍伴奏靜音、EQ 指定頻率衰減、壓縮超過門檻的訊號、混響預延遲與立體聲尾音、限幅器、同步時間剪輯的 MP4／WAV／MP3 長度及音訊位置與 MP4 影像位置、合成可變影格率影片轉為 30 fps、取消與來源保護。
- 3 項 UI 操作測試：真實 FFmpeg 媒體匯入，Qt 工作執行緒交接，控制數值與音效預覽渲染，分割／刪除／復原／裁切，專案儲存與重新開啟；更換較長影片時的終點更新；非法裁切不破壞保留片段。
- Qt 介面離屏啟動與實際截圖。截圖使用合成測試影片和音訊，並非實際薩克斯風演奏。

UI 自動測試隔離媒體裝置播放；Linux Qt5 沒有可用的 multimedia service。因此 **未驗證實際喇叭播放、聲畫同步、Qt6 的媒體解碼或 Windows 安裝**。

尚待驗證：

1. Win11：PySide6 啟動、音訊裝置、預覽播放／暫停／seek、兩個播放器的同步和剪輯點跳轉。
2. 外接麥克風的真實演奏錄音：前奏比對及整首歌的結尾同步。
3. 真實 MOV／HEVC／可變影格率檔案、手機旋轉資訊和 SDR 色彩。
4. 1080p／4K 長影片、多個剪輯點的速度與記憶體。
5. PowerShell 建置、PyInstaller 可攜版、Inno Setup 安裝／解除安裝，以及在未裝 Python 的 Win11 上啟動。

`scripts/build-windows.ps1` 在 Windows 打包前會重新執行測試；請保留測試輸出供後續比較。

## Sax Cover Studio 0.1.2（2026-10-12）

基礎：使用者上傳的 0.1.1 原始碼。環境：Linux、Python 3.13.5、Qt 5.15.15 / PyQt5、FFmpeg 7.1.5、NumPy 2.2.4、SciPy 1.15.3。

**27 項測試全部通過：16 項核心測試、11 項 UI／啟動／资源測試。** 實際輸出保留於 `docs/test-results.txt`。

- 沿用上傳版本的核心測試，涵蓋 EQ、壓縮、卷積混響、−1 dBFS 限幅、伴奏效果隔離、音量／位移、對齊、剪輯、可變影格率、影片串流起始時間偏移修正，以及專案讀寫／取消／來源保護。
- 新增：Comp／Revb 預設關閉及收合；箭頭不影響專案或音效開關；開關不清除參數；關閉時參數控制停用。
- 新增：原音色預設保持效果啟用行為；載入舊專案還原開關與參數。
- 新增：模擬 PyInstaller `_MEIPASS` 資源目錄，驗證 ICO 與啟動插畫可載入；ICO 的 10 個尺寸均可被 Qt 讀取。
- 新增：執行真正的入口啟動流程，驗證啟動畫面出現、初始化後關閉，並交接到可見的主視窗。
- 靜態核對：PyInstaller 使用新 EXE 名稱、ICO 及 assets 資料目錄；Inno Setup 的圖示、捷徑、AppUserModelID 與程序一致。
- 完整性核對：`engine.py`、`alignment.py`、`media.py`、`qt.py`、`widgets.py` 與上傳 0.1.1 逐位元一致。

UI 測試的設定檔隔離在暫存資料夾，不修改本機原有使用者偏好。實際介面截圖使用 FFmpeg 產生的合成素材與影片縮圖；播放器訊號在截圖腳本中隔離。

此環境沒有可用的 Qt5 multimedia service，亦無 Windows／PySide6，因此 **未驗證 Win11 實際播放、工作列顯示、PowerShell／PyInstaller 的 Windows EXE 建置或 Inno Setup 安裝**。這些項目需在 Win11 建置時驗收；本交付包不含預建 Windows EXE。

## 0.1.1 修改（2026-10-12）

- 修正：影片串流起始時間晚於容器／音訊時，從中段開始的剪輯片段畫面會偏移（實測 0.3 秒偏移造成 300 ms 不同步，修正後 0 ms）。新增 `test_cut_stays_in_sync_when_video_starts_after_audio`。
- 新增 `test_effects_do_not_touch_backing_track`：EQ／壓縮不影響伴奏軌。
- 限幅器上限改為 −1 dBFS；專案檔損毀或缺欄位時回報可讀的錯誤。
- 介面：Fusion 風格修正 Win11 數字欄左側箭頭無反應；剪輯區可收合；第一軌／第二軌與總輸出限幅器標示；暫停時 seek 顯示實際畫面；預覽同步改以音訊為主；等待媒體載入不再卡住；匯出預設存到影片所在資料夾；移除 x264 兩執行緒限制。新增 3 項 UI 測試。
- 此環境只有 FFmpeg 6.1 且無 Qt：核心測試除兩項混響測試（需 FFmpeg 7.1 的 `irnorm`）外全部通過；UI 測試需在 Win11 建置時執行。
